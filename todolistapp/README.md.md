
# To-Do List 

A user-friendly desktop To-Do List application built with Java Swing. It allows users to create, check off, and reorder tasks with drag-and-drop functionality. The app features theme switching (Pink/Blue), persistent task saving using file serialization, and a modern, animated UI with responsive buttons and hover effects.


## Features

- ✅ Add and delete tasks
- 🔁 Drag-and-drop task reordering
- 🎨 Theme switching (Pink & Blue)
- 💾 Persistent task saving (via file serialization)
- 🌈 Responsive buttons with hover effects
- 📅 Displays current date
- ☑️ Check off tasks as completed
- ⚙️ Theme preference saved locally
- ❌ Close app button also saves tasks before exit


## Clone and Run the Project

Clone the repository

```bash
  git clone https://github.com/your-username/your-repo-name.git
```

Go to the project directory

```bash
  cd your-repo-name
```

Compile the Java file

```bash
  javac ToDoListApp.java
```

Run the application

```bash

```
